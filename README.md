# Mirror

The morning brief.

Live: https://dong-xuyong.github.io/mirror/

Days live in the private repo Dong-Xuyong/progress-sync, file mirror.json.

The page loads that file on open, on focus, and every 60 seconds.

Grok writes the brief. You edit the answer to the morning question, and that saves to `mirror.json` a few seconds after you stop typing.

You also log today's Top 3, mood, sleep, sunlight, and caffeine. Those save to `journal.json` for the Europe/Lisbon date. With no GitHub token, the page shows "Connect sync to save."

CONTRACT.md is the writer spec.
