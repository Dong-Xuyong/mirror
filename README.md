# Mirror

The morning brief.

Live: https://dong-xuyong.github.io/mirror/

Days live in the private repo Dong-Xuyong/progress-sync, file mirror.json.

The page loads that file on open, on focus, and every 60 seconds.

Grok writes the brief. The page shows today's weather on one line, the sunlight note, and reads the brief aloud.

Mood, sleep, and the day's priorities are logged in the [journal](https://dong-xuyong.github.io/journal/).

CONTRACT.md is the writer spec.
